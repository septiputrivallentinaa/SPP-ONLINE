# SPP-ONLINE
SPP SMK 3 Banjarbaru ini dikelola admin untuk administrasi keuangan sekolah. Fiturnya: master data SPP (tahun &amp; nominal), data Kelas, dan database Siswa. Menu Pembayaran mencatat transaksi setoran bulanan digital secara dinamis di localhost. Fitur Petugas mengatur hak akses staf, dan Logout mengamankan sesi pengguna agar data aman.
